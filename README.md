# WestoryVisa

WestoryVisa is a visa-application workspace with guided intake, document processing, form-practice tools, payment flows, and supporting browser-extension components.

## Repository layout

- `frontend/`: product site and application workspace
- `backend/`: API and service integrations
- `docflow-chrome-extension/`: browser-extension source
- `visa-form-practice-lab/`: standalone form-practice experience
- `tests/`: automated tests
- `deploy/`: example deployment configuration

## Local setup

Start with the example environment files and the component-specific README files. Never commit real credentials, customer documents, runtime databases, or local browser profiles.

See [GITHUB_BACKUP_SCOPE.md](GITHUB_BACKUP_SCOPE.md) for the public repository boundary.
