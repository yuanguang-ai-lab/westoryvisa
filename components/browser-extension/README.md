# WestoryVisa Chrome 正式网站版 1.0.5

只连接 https://westoryvisa.com 和 CEAC，继承 1.0.4 r3 提速执行器。

解压后在 chrome://extensions 开启开发者模式，加载此目录。登录正式网站，进入客户档案的逐页填写页，在“会员插件填写”连接当前档案。人工进入 CEAC 表格后开始。无需本地服务。

服务器强制有效会员、原登录会话、账号/机构权限和并发租约；每用户一份、机构默认三份。断线两分钟后需重新准备。照片前任务完成即清除服务端计划和插件授权。

本包尚未上架 Chrome 商店。安装说明：https://westoryvisa.com/extension.html
