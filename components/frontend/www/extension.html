会员填写插件

在自己的 Chrome 中填写 DS-160。使用 WestoryVisa 当前登录账号的有效会员权限，无需安装 Python 或本地服务。

下载插件 1.0.5

  1. 下载并解压 ZIP，保留解压后的目录。
  2. 在 Chrome 地址栏输入 chrome://extensions，开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压目录。本版本尚未上架 Chrome 应用商店。
  3. 登录 WestoryVisa，打开中国版客户档案的“DS-160 逐页填写”页面，找到“会员插件填写”。安装或更新后请刷新工作台。
  4. 打开 CEAC，人工完成验证并进入正式表格。回到工作台点击“连接当前档案”，再点击“开始填写”。
  5. 插件核对字段后连续翻页，到照片页停止。验证码、照片和最终签署提交由使用者处理。

更新时请先停止任务，替换原解压目录的文件，在扩展管理页面点击“重新加载”，然后刷新工作台和 CEAC 页面。

账号与会员

每个账号同时运行一份任务，机构默认同时三份。停止任务立即释放；断线两分钟后释放，需重新准备。会员到期或退出原登录会话后，服务器不再确认后续操作。

资料使用

插件通过 HTTPS 从 WestoryVisa 领取当前授权档案的填写计划，在 CEAC 表单中填写并回传进度。授权令牌和计划保存在扩展会话存储中，任务结束或过期后清除。请仅为你获授权处理的申请人使用。隐私政策
