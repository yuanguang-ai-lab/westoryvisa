# WestoryVisa 真实支付接入

最终支付渠道确定为四方聚合支付。仓库和生产服务器目前没有该服务商的正式接口文档、商户资料或签名规则，所以线上保持“待接入”状态，不能猜测参数或伪造交易成功。

## 已实现

- 商品：月度会员 ¥199 / 30 天、年度会员 ¥1,990 / 365 天。
- 订单、支付流水、退款、会员有效期和回调事件的数据结构。
- 回调的金额与币种核对、事件幂等和会员开通边界。
- 待支付查单、退款状态和会员时长重新计算逻辑。
- 数据隔离：订单、支付、退款和会员均绑定机构账号。
- 会员门禁：未购买或已过期账号无法访问工作台和客户案件接口。

## 上线前必须由商户完成

1. 取得四方聚合支付的正式接口文档和测试环境。
2. 确认商户号、通道编码、下单地址、查单地址、退款地址和异步通知格式。
3. 确认签名算法、字段排序、字符编码、密钥或证书格式、时间戳与重放保护规则。
4. 确认支付成功、处理中、失败、退款成功等状态码，以及通知重试和响应要求。
5. 先在测试环境完成下单、验签、重复通知、错金额拦截、查单和退款，再配置正式商户资料。

## 渠道说明

当前月度和年度方案按一次支付购买固定有效期设计，不声称自动续费。最终支持的微信、支付宝或其他通道，以四方服务商实际开通的产品和合同为准。

密钥、证书、合同、身份证明和结算资料不得提交到 GitHub。
