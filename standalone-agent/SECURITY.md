# Agent security contract

以下约束由代码执行，不依赖模型提示词：

- 只允许 HTTPS `ceac.state.gov/GenNIV/` 页面；
- URL 中禁止凭据和 password、token、otp 等敏感查询参数；
- 未匹配版本化页面计划的页面立即转人工；
- 每页只能使用明确允许的字段、动作和按钮；
- 只有人工确认字段可写入，模型提供的值会被丢弃；
- 字段风险等级来自系统 schema，模型不能降低风险；
- 敏感 DS-160 问题始终由人工填写；
- CAPTCHA、登录凭据、一次性验证码始终由人工处理；
- Sign、Submit、Pay、Delete 等不可逆目标被阻止；
- 页面内疑似提示注入或外传指令触发人工复核；
- 每个动作执行前保存检查点，执行后重新观察；
- 控件值、URL 或明确浏览器回执必须通过确定性验证；
- 提议动作的模型不能单独证明自己的动作成功；
- 模型的 `COMPLETE` 必须通过必填项和错误状态检查；
- 恢复时先验证 pending action，结果不确定就停止，绝不重复执行；
- 固定最大步数，验证失败不会无限重试；
- 检查点目录为 `0700`，文件为 `0600`；
- 明文开发检查点会删除证据 excerpt，生产服务默认要求加密；
- 原始文档字节、完整 OCR、密码和验证码不进入检查点；
- Gemini Computer Use 使用 `previous_interaction_id` + `function_result`
  保持逐步视觉会话；真实资料试跑前必须完成 Gemini 数据保留与隐私评审；
- 隔离构建不得导入 DocFlow 应用。

生产部署还必须由基础设施完成：

- 每租户密钥、密钥轮换和访问审计；
- 签名短时任务令牌与撤销；
- 加密对象存储和确定的保留/删除策略；
- 浏览器直播遮罩、截图脱敏和 profile 销毁；
- 审计日志完整性保护；
- 限流、恶意文件扫描、文件类型与大小限制；
- provider 数据保留关闭及跨境/隐私评审；
- CEAC 页面变化监控和页面计划版本回滚。

离线 demo 的明文检查点只可使用固定假数据，不能放真实客户信息。
